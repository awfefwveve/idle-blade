# 메인 전투 화면 우선 제작

## 확정된 화면 구조
- 하단: 전투 / 각성 / 던전 / 중앙 스테이지·보스 도전 / 상점 / 소환 / 패스.
- 기존 로비를 유일한 메인 전투 화면으로 사용한다. 별도 전투 화면 전환은 제거한다.
- 각성은 메뉴 자리만 확보한다. 환생·초기화 등 실제 규칙은 이번 변경에서 추가하지 않는다.
- 방치 보상과 장비 소환 카드는 X로 완전히 닫는다. 접힌 카드나 다시 열기 버튼을 화면에 남기지 않는다. 닫힘 상태는 재접속 후에도 유지한다.
- 우측 성장 메뉴는 기존 전체 접기/펼치기를 유지한다.

## 작업 순서
1. 현재 메인 전투 화면의 배치와 UI 에셋을 먼저 완성한다.
2. 배경, 주인공 성장 단계, 일반 몬스터, 보스, 공격·처치·재화 획득 연출 에셋을 규격에 맞춰 교체한다.
3. 이후 각 메뉴를 하나씩 열어 해당 기능 개발과 전용 에셋 제작을 함께 완료한다.

## 첫 에셋 묶음 범위
- 공통 프레임, 버튼의 기본/선택/비활성 상태, 닫기 및 서랍 화살표.
- 상단 초상화 틀, 재화 아이콘과 슬롯, 공지·우편·설정 아이콘.
- 좌측 메뉴, 우측 성장 메뉴, 하단 6개 메뉴 아이콘.
- 중앙 스테이지 진행 경로·보스 표식·도전 버튼.
- 임무, 방치 보상, 장비 소환 카드의 장식 이미지.
- 반복 가능한 전투 배경과 별도 캐릭터·몬스터·효과 이미지.

화면 기준 좌표는 현재 1672×941이다. 글자·수치·진행바는 코드로 표시하며 이미지에 굽지 않는다. 최종 출력 크기·피벗·애니메이션 프레임 규격은 개별 제작 목록에서 확정한다. 기존 완성 화면 전체를 한 장의 배경으로 사용하지 않는다.

## 이번 수정 검증
- Unity 참조 기반 C# 컴파일 통과.
- 실제 Unity 화면 클릭 검수는 아직 수행하지 않았다.
