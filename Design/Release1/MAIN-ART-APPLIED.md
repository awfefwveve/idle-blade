# GPT 메인 화면 에셋 1차 적용

## 반영
- 내장 GPT 이미지 생성 도구로 29종 생성. PixelLab 호출은 아직 하지 않았다.
- 원본 PNG를 client/Assets/Resources/Art/Main에 복사하여 프로젝트가 외부 생성 폴더에 의존하지 않도록 했다.
- 배경, 주인공 기본형, 별도 도끼, 일반몹, 보스, 공통 패널과 23개 아이콘. 무기 아이콘은 별도 도끼를 재사용한다.
- 상단 재화, 좌우 메뉴, 하단 6개 메뉴, 초상화, 임무 보석, 소환 카드 무기, 처치·코인 흡수 연출에 연결했다.
- 패널은 공통 9-slice 렌더링을 사용한다. 선택 상태는 색 강조를 더한다. 별도 선택/눌림 상태 원화는 아직 없다.
- 버튼 위치, 전투/각성 구분, 카드 완전 닫기, 성장 서랍 구조는 유지한다.
- IdleBlade → Art Preview 메뉴에 서버 연결 없는 읽기 전용 미리보기 추가. 예시 데이터임을 화면에 표시하며 재생 모드에서는 사용하지 않는다.

## 검증과 제한
- 런타임과 Editor 미리보기 코드의 Unity 참조 기반 C# 컴파일 통과. 기존 JSON 역직렬화 필드 경고만 남음.
- 생성 이미지의 시각적 형태를 검토하고 첫 묶음 배경은 불투명, 캐릭터/아이콘은 투명 alpha임을 확인했다.
- Unity 화면 조작 도중 사용자의 물리 Esc 입력으로 Computer Use가 중단되었다. 이후 화면 조작하지 않았다. 최종 Unity 화면·클릭 검수는 미완료다.
- 이번 PNG는 생성 원본이다. 가져오기 크기 제한과 화면 배치를 적용했지만 최종 32/48/128px 픽셀 납품본으로 정규화한 것은 아니다.
- 주인공/몬스터는 정지 그림에 기존 이동·상하 움직임을 적용한다. 도끼는 기본 손 위치에 맞춘 회전 연출이다. 달리기·공격·피격 애니메이션 시트가 아니다.
- 성장 단계 g02/g03, 프레임별 무기 소켓, 분리 배경 레이어·완전한 심리스 반복, 전용 카드 삽화, 광폭/베기 이펙트 시트는 남아 있다. 배경은 현재 좌우 반전 반복을 유지한다.
- 유물 아이콘 목걸이의 상단 잘림, 도끼 가장자리의 약한 빛, 일부 아이콘의 지나친 금색은 다음 정리 대상이다. 최종 상용 에셋 검수 완료로 간주하지 않는다.
- 생성 프롬프트·원본 경로·프로젝트 파일 매핑은 MAIN-ART-GENERATION.json, 원본 모아보기는 MAIN-ART-GALLERY.html.
