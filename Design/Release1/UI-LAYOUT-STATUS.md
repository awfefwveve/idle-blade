# UI 배치 검수 기록

사용자의 로비.png / 전투.png를 배치 기준으로 사용. 배경 이미지 한 장으로 UI를 대체하지 않고 각 영역을 개별 버튼/표시로 구현한다. 두 화면 모두 1672×941 좌표를 사용하며 안전 영역 안에서 비율 유지.

## 이번 조정
- 상단 프로필·재화 4칸·우편·설정, 로비의 공지/칭호 위치 유지.
- 로비 좌측 세로 메뉴와 이벤트 카드, 우측 성장 메뉴 8칸, 하단 임무/스테이지/방치/소환 카드, 중앙 대형 전투 시작.
- 전투의 스테이지 진행선, 타이머, 우측 상태/보스 영역, 좌하단 분노/HP, 중앙 원형 스킬 3개와 이름·설명, 우측 원형 전투/배속 버튼.
- 전투 맨 아래 임무 카드와 로비/전투/던전/상점/소환/패스. 계정·랭킹은 설정 내부.
- 전투 메뉴는 실제 일시정지가 아니므로 자동사냥이 계속된다는 안내와 로비 복귀 제공.
- 미구현 재화는 —, 스킬은 미구현 표시. 서버 값과 예시 이미지의 수치를 섞지 않는다.

## 확인 결과와 남은 범위
C# 컴파일 통과. Unity 에디터에서 재실행해 로비와 전투 전환, 원형 컨트롤, 하단 카드 위치를 직접 확인했다. 현재 작은 Game 뷰에서는 글자가 작으므로 최종 기기 해상도의 글자 선명도·터치 영역 검수는 추가 필요하다.
정교한 테두리/아이콘, 스킬 그림, 보스 초상, 완성 배경은 아직 교체 전이다. 현재 임시 캐릭터의 체형 차이 때문에 참고 이미지와 시각적 무게가 완전히 일치하지 않는다. 출시 UI 완성으로 간주하지 않는다.
새로운 전투 기능 및 서버 규칙은 이번 작업에서 변경하지 않았다.

## 로비 상시 전투 변경
- 중앙 하단 전투 시작 버튼을 현재 스테이지/보스 자격/도전으로 교체. 로비에서 직접 보스 도전하며 기존 서버 승패/다음 스테이지 처리를 공유.
- 주인공 화면 좌표는 고정, 적 접근 및 배경 트랙 이동은 표시 연출. 서버 스냅샷에서 적 체력 회복/스테이지 변경을 감지해 다음 접근 연출을 시작.
- 현재 한 장의 영웅 그림은 달리는 동안 상하 움직임으로 표현. 정식 달리기/공격 프레임은 미제작이며 실제 다중 몬스터 이동 판정 구현과는 구분.
- 방치/소환 카드는 닫기 및 다시 열기, 성장 메뉴는 슬라이드 접기/펼치기. 로컬 표시 설정 저장.
- 상단 재화 아래 추가 UI 공간 비움. 기존 전투 탭은 상세 전투 보기로 유지.
- C# 컴파일 통과. Unity에서 새 로비 배치 및 방치 카드 닫기를 직접 확인. 로그인되지 않은 상태여서 실제 온라인 이동/보스 연출은 화면 검수 미완료. 사용자 조작이 감지되어 추가 UI 조작은 중단.
