# 전방위 군집 전투 1차

사용자 최신 요청에 따라 기존 오른쪽 한 줄 진입을 변경했다.

- 8개 방향에서 1초당 4마리 묶음 생성, 최대 40마리. 상한 중 밀린 생성량은 쌓지 않는다.
- 서버의 기존 x 필드는 이제 주인공까지의 방사 거리(mm)로 사용한다. sector가 접근 방향이며 모든 방향에 동일한 거리 판정을 적용한다. 자유 2D 이동·몬스터끼리의 충돌 회피는 아니다.
- 가까운 대상 3마리, 광폭 7마리 타격을 유지한다. 기존 몬스터는 ID로 방향을 보충하고 남은 체력을 유지한다.
- 위쪽은 정면/앞대각선, 아래쪽은 등/뒷대각선, 좌우는 측면. 좌우 반전을 포함해 8개 방향을 표시한다. GPT 신규 정지 스프라이트 4종, 지형 가림 1종 생성.
- 화면 위치는 거리와 방향을 투영하며 깊이에 따라 약한 크기 변화를 준다. 먼 상단 적 → 능선 → 가까운 후면 적 → 주인공 → 앞쪽 적 → 효과 → 전경 잔해 → UI 순서로 그린다.
- 서버가 순번 있는 실제 타격·처치 이벤트를 보낸다. 기록은 최대 96개, 효과 최대 40개. 클라이언트는 이미 처리한 순번을 재생하지 않고 첫 접속 때 과거 효과를 건너뛴다.
- 2초 단위 응답의 타격 효과를 짧은 시간차로 재생한다. 붉은 파편, 움찔거림, 짧은 잔해, 주변 베기 궤적을 추가했다. 완성된 프레임 애니메이션이나 고어 절단 에셋은 아니다.
- 생성 밀도 증가로 온라인 수익 속도가 달라진다. 최종 경제 밸런스는 별도다. 보스/방치 계산은 이번에 바꾸지 않았다.

검증: 서버 테스트 21개, 실제 Nakama 로그인·처치 보상·강화 저장·중복 요청 거부 통과. 런타임/Editor C# 컴파일 통과. Unity 읽기 전용 미리보기에서 방향별 24마리, 앞뒤 겹침 및 UI 배치 확인. 실제 로그인 플레이의 연속 움직임 검수는 미완료.

남은 전투 작업: 방향별 연속 달리기/피격 프레임, 주인공 공격 동작, 실제 피해와 쿨타임이 있는 자동 스킬, 몬스터 반격·플레이어 사망. 이번 범위는 전방위 진입과 타격·처치 표현이다.
