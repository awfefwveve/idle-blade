# 사냥 처치·보상 피드백

## 구현
- 온라인 실제 처치 수와 실제 지급 골드 누적치를 서버 저장에 추가. 잔액 차이로 보상을 추측하지 않는다.
- 서버에서 새 처치가 확인되면 쓰러지는 적, 골드 획득 문구, 흩어졌다가 상단 골드 슬롯으로 곡선을 따라 이동하는 동전 표시. 최대 48개로 효과 수 제한.
- 재접속 첫 스냅샷은 기준값만 설정하며 과거 처치 연출을 재생하지 않는다. 오프라인 보상과 강화 지출은 처치 효과를 발생시키지 않는다.
- 적 교체는 체력이 증가했는지 추측하던 방식에서 실제 처치 누적치로 전환. 다음 적이 빠르게 접근하고 뒤의 2개 대기 실루엣으로 유입을 표현한다.
- 대기 실루엣은 아직 실제 다중 대상 판정 대상이 아니다. 단일 활성 대상 서버 구조는 유지했다.
- 보스 승리 시 클리어 배너, 다음 스테이지. 첫 보스 클리어 이후 선택형 자동 보스 도전. 기본 OFF, 실패 시 OFF. 계정 변경 시 OFF.
- 골드만 실제 보상으로 연출. 미구현 장비·보석 드롭을 가짜로 표시하지 않는다.

## 검증과 한계
서버 단위 테스트 17개, C# 컴파일 및 실제 서버 사냥/강화/재요청 검사 통과.
본편 500스테이지 테이블, 지역별 15종 몬스터, 50ms 군단 전투, 최종 보스 수치는 아직 미이행이다. 이번 작업은 기존 시제품의 처치-보상-다음 적-보스 진행 연결이며 전체 기획 완성을 뜻하지 않는다.
보상 비행은 2초 서버 동기화 후 묶어서 표시되므로 프레임 단위 타격 동기화와는 차이가 있다. 실행 중 실제 보상 효과의 시각 검수는 로그인된 플레이에서 별도 확인 필요.
