# 광폭화 첫 구현

- 서버 평타 이벤트당 분노 8, 100 도달 시 6초 광폭화. 발동을 일으킨 평타 다음 공격부터 피해 보너스 적용.
- 피해 +25%(내림), 공격속도 +35%. 현재 1초 시뮬레이션에서 정수 누적값 100/135로 공격 횟수를 분배한다. 최종 50ms 전투 코어의 정확한 공격 간격 구현은 별도다.
- 광폭화 종료 후 2초간 충전 금지. 보스 입장/종료, 방치 정산 때 초기화. 방치 골드에 광폭 보너스는 아직 적용하지 않는다.
- 전투 화면 분노 게이지, 서버 기준 남은 초, 임시 붉은 효과, 몸체 15% 확대, 빠른 공격 연출. UI는 2초 동기화 스냅샷 기준으로 표시한다.
- 새 에셋 생성 없음. 기존 저장 schema 2에 필드를 기본값으로 추가하여 호환 유지.
- 범위 +50%와 추가 대상 +4는 다중 대상 전투 이후 구현. 현 단일 적 화면에서 구현된 것으로 표시하지 않는다.
- 검증: 경제/보스/분노 16개 단위 테스트, Unity 참조 기반 C# 컴파일, 실제 서버 로그인·랭킹 회귀 검사. Unity 화면 조작 검수는 남아 있다.
