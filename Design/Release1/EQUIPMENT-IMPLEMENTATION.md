# 장비 구현 단위 — 2026-09-27

원천: SourceData/weapons.json, armor.json, weapon_families.json, enhancement_curve.json 및 기획서 6절.

## 적용
- 장비/무기/방어구 기존 진입 버튼에 실제 목록·상세 패널 연결. 메인 HUD 배치 유지.
- 무기 18종, 방어구 18종. 사용권·중복·보존 수량 분리.
- 소유한 장비 장착, 장착 전후 공격력/HP 비교, 기본 공격 간격·범위·대상 표시.
- 무기/투구/갑옷/장화 슬롯 강화 최대 200. 골드·광석 동시 차감. 장비 교체 후 유지.
- 중복 5개 합성, 하위 등급부터 최대 200회 일괄 합성 견적/확정, 중복 보존 수량 제외.
- 중복 1개씩 분해, 확인창에 등급·수량·광석 표시. 영웅 이상 서버 확인 플래그 필수. 사용권 소비 불가.
- 장비 명령에 저장 버전 검사, 보스전 중 변경 금지.
- 장비 공격 배율·평타 계수·공속·범위·대상 수, 방어구 HP·슬롯 강화·최상위 등급 세트만 적용. 망치 세 번째 유효 공격은 일반 적 이동을 4틱 정지.
- 최초 일반 도끼/일반 갑옷 사용권. 첫 보스 클리어 고급 도끼 1회 지급(기존 기클리어 계정도 1회 보충).

## 검증 및 한계
- C# 컴파일 통과, 서버 회귀 38/38, 실제 Nakama 장비 36종/최초 사용권/장착 저장/미보유 장착과 사용권 분해 거절 확인.
- DB 적용 전 백업: work/before-equipment-v1.dump.
- 소환·장비 던전은 다음 단위. 따라서 일반 플레이의 중복 장비/광석 공급 경로는 아직 완성되지 않았다. 테스트용 아이템을 실제 계정에 지급하지 않았다.
- 무기·방어구별 교체 스프라이트 미연결. 현재 전투 외형은 공통 임시 아트이며 전투 판정과 수치는 장착값을 사용한다.
- 일반 적 공격/피격 경직 전체 전투 코어 및 방치 시뮬레이터는 별도 미완료 사항이다.
- 장비창 실제 클릭/해상도별 시각 검수 미완료. 장착 프리뷰의 수치는 서버에서 산출한다.
