# 장비 소환 구현 — 2026-09-27

## 연결된 규칙
- 기존 소환 버튼 내부에 무기/방어구 탭, 1/10회, 비용 확인, 확률 안내, 최근 저장 결과 표시.
- 메인 2 최초 클리어 이후 해금. 무기 티켓 10장을 1회 지급하며 기존 기클리어 계정에도 중복 없이 보충.
- 배너별 KST 오전 5시 일일 무료 1회. 무료 → 해당 배너 티켓 → 무료 보석 → 유료 보석 순서, 전량 지불 불가 시 전체 거절.
- 원본 summon_probabilities.json의 6등급 가중치와 등급 내 계열/부위 각 1/3. 개별 전체 확률 및 보장 회차 확률 표시.
- 무기/방어구 독립 천장: 전설 이상 미획득 199회 다음 보장, 자연 신화 유지. 10회는 순차 판정.
- UUID v4에서 별도 난수를 취하고 rejection sampling 적용. 공개되는 전투 RNG 상태로 추첨하지 않음. Nakama uuidv4 API 명칭은 Heroic Labs 공식 운영진의 안내와 실제 서버 실행으로 확인.
- 요청 ID 영수증 별도 보관. 결과·이전/이후 천장·차감 구성·시각·버전을 재화/보유 장비와 같은 storageWrite로 저장.
- 동일 요청은 같은 영수증 재조회, 다른 payload의 동일 ID 재사용 거절. 최근 결과는 재접속 sync로 복구.

## 검증
- 기존 서버 38개 + 소환 전용 6개 통과. C# 컴파일 통과.
- 실제 서버의 별도 신규 테스트 계정으로 10회 소환, 난수 API 실행, 영수증 재조회, 티켓 1회 차감, 결과/인벤토리 저장 확인.
- summon-smoke.cjs는 자신이 생성한 신규 테스트 계정만 DB에서 2클리어로 준비한다. 사용자 저장에는 손대지 않는다.
- 백업: work/before-summon-v1.dump.

## 미완료
- 스킬 소환은 스킬 시스템과 함께 연결할 다음 단위.
- 유료 보석 수납을 위한 결제 연동·영수증 검증은 없음. 유료 잔액 분리/차감 규칙만 구현.
- 소환 전용 애니메이션, 모바일 시각 검수, 외부 확률 고지 페이지 및 출시 법률 검토 미완료.
- 던전의 광석·장비 티켓 공급은 아직 미구현. 현재 장비 공급은 무료/기존 보석/초기 티켓이며 광석은 중복 분해로 획득 가능.
