# 일반사냥 다중 몬스터 첫 구현

- 서버가 개별 몬스터 ID, X 위치, 현재/최대 체력을 저장한다. 일반사냥은 50ms 단위로 계산한다.
- 0.5초마다 생성하며 최대 40마리. 상한 중 놓친 생성량은 나중에 몰아서 생성하지 않는다.
- 기본 도끼는 1.6m 안의 가까운 적 최대 3마리, 공격 간격 0.8초.
- 광폭화는 범위 2.4m, 최대 7마리, 피해 +25%. 공격 간격은 50ms 단위로 양자화한 0.6초다.
- 분노는 맞힌 몬스터 수와 무관하게 유효 공격당 8만 증가한다.
- 처치마다 서버가 골드와 보스 도전 자격을 계산한다. 클라이언트는 서버 목록을 바탕으로 접근, 체력바, 피격을 표시한다.
- 로비와 전투 화면 모두 같은 서버 몬스터 목록을 사용한다. Y축 차이는 시각 표현이다.

## 검증

- 경제/보스/분노/다중 대상 단위 테스트 19개 통과.
- Unity 참조를 사용한 C# 컴파일 통과.
- 실제 Nakama에서 로그인, 복수 몬스터의 고유 ID·생존 체력·위치, 처치 보상, 강화 저장, 중복 요청 거부 확인.
- 로그인한 Unity 화면에서의 연출 검수는 아직 수행하지 않았다.

## 남은 범위

- 보스는 기존 1초 계산, 방치 보상은 기존 단일 대상 수익 계산을 유지한다.
- 일반 몬스터의 주인공 공격/사망 처리, 최종 500스테이지 수치표 적용은 별도 작업이다.
- 임시 몬스터 그림을 사용하며 클라이언트 목록은 2초 동기화 기준이다. 정확한 공격 이벤트별 애니메이션 동기화는 아직 아니다.
- RAGE-SLICE.md의 단일 대상/범위 미구현 설명은 일반사냥에 한해 이 문서로 대체한다.
